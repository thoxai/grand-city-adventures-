# Assets und Lizenzen

| Bestandteil | Herkunft | Lizenz |
|---|---|---|
| Gebäude, Straßen, Bäume, Laternen, Requisiten | prozedural im Code erzeugt (`CityBuilder`, Shader) | Projekt-eigen |
| Figuren (Alex, Mia, NPCs) | prozedural aus Primitiven (`HumanoidModel`) | Projekt-eigen |
| Fahrzeuge (Lumen K2, Vireo RS) | prozedural aus Primitiven (`CarModel`) | Projekt-eigen |
| Shader (Fassade, Boden, Pflaster, Wasser) | selbst geschrieben | Projekt-eigen |
| Motorsound | zur Laufzeit synthetisiert (`EngineAudio`) | Projekt-eigen |
| Icon (`icon.svg`) | selbst gezeichnet | Projekt-eigen |
| Story, Dialoge, Namen, Orte | selbst geschrieben | Projekt-eigen |
| Schrift | Godot-Standardschrift (Open Sans / Noto, im Engine-Binary enthalten) | SIL Open Font License |
| Engine | Godot Engine | MIT |

Es werden **keine externen Asset-Dateien** geladen. Alle Namen (Fahrzeugmodelle, Firmen wie „Graufeld
Logistik“, Personen) sind frei erfunden; Ähnlichkeiten wären zufällig. Es werden keine Figuren, Logos, Karten
oder sonstigen Inhalte der GTA-Reihe oder anderer geschützter Spiele verwendet.

Beim Austausch gegen externe Modelle (z. B. von Poly Haven, Kenney oder Quaternius) bitte Lizenz (bevorzugt
CC0) und Quelle hier ergänzen.
